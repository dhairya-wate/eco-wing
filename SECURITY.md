# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within the EcoWing system, please report it privately.

**DO NOT file a public issue.**

Please send security reports to:
- **Security Contact**: `security@example.com` (placeholder)

Include in your report:
1. Component affected (`services/command-center`, `services/sensor`, `contracts/`, `deploy/`)
2. Step-by-step reproduction instructions or proof-of-concept
3. Potential impact assessment

We acknowledge reports within 48 hours and coordinate fixes before public disclosure.
